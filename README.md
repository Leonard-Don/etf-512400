# 512400 ETF Research Console

有色金属ETF南方（512400）的本地研究工作台。当前版本已整理成稳定自用版：第一屏以“今日决策台”为主，自动优化给主口径，信号实验室负责解释原因和风控约束。

## 功能

- ETF 核心指标：价格、净值、折溢价、日涨跌、规模、前十大集中度、季度跟踪差
- 因子拆解：黄金链、铜钼链、稀土链、铝链、锂钴链
- 情景压力（What-If）：基准、黄金避险、美元利率、需求走弱；仅做静态投影，主决策与信号不会随情景重算
- 商品驱动：沪金、沪铜、沪铝、碳酸锂、稀土产业指数
- 今日决策台：聚合主动作、主仓位、核心风险和商品风险排序
- 信号实验室：趋势、因子、折溢价、流动性和风险预算合成当前动作与建议仓位
- 自动策略优化：系统搜索趋势窗口、回撤档位和风控阈值，并用样本外验证评分
- 跟踪与交易质量：对比 000819 基准，监控跟踪差、折溢价温度和成交额分位
- 动态策略回测：买入持有、趋势跟随、回撤低吸、因子共振；收益展示统一标为历史参考
- 本地历史缓存：刷新后追加 `src/data/history/512400-snapshots.json`
- 持仓暴露：2026Q1 前十大重仓股和篮子归类
- 事件流与数据管线：公告、交易、风控、因子事件

## 数据刷新

```bash
npm run refresh:data
```

刷新脚本会写入 `src/data/liveSnapshot.json`，当前接入：

- 东方财富行情接口：价格、前收、成交额、换手、交易时间
- 东方财富日线接口：512400 复权日 K 线，用于趋势画像和策略回测
- 东方财富指数日线接口：000819 基准 K 线，用于跟踪质量判断
- 东方财富期货/指数接口：商品驱动报价与近 60 日 K 线
- 天天基金净值趋势脚本：单位净值、累计净值、阶段收益、近 280 日净值序列
- 天天基金估算净值脚本：盘中估值与估算涨跌幅
- 本地历史缓存：每次刷新追加一条紧凑研究快照

## 目录

  App.css                  页面样式

## 数据口径

内置样例数据主要来自：

- 上交所：南方中证申万有色金属ETF 2026年第1季度报告
- 中证指数：中证申万有色金属指数编制方案
- 天天基金：512400 基金档案
- 东方财富：2026-04-30 行情快照
